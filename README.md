# 一秋的工作台

> My personal workspace — if you like it, feel free to fork and make it yours~

专属于我的个人工作台，手机端优先，天青色主题。

## 功能模块

| 模块 | 说明 |
|------|------|
|  主页 | 方块布局，各模块数据一览 |
| 📋 待办 | 批量输入自动解析，完成鼓励/未完成安慰，历史统计 |
| 🎬 创作 | 灵感随笔 → 文案整理 → 视频项目，全流程管理 |
| 📚 成长 | 多邻国打卡、阅读进度、健身统计（自动关联待办） |

## 技术栈

- 纯 HTML / CSS / JS，单文件应用
- localStorage 本地数据持久化
- 天青色主题（#5B9EB5），Refero 设计风格
- 支持侧边栏 / 底边栏两种布局

## 本地开发

```bash
cd yiqiu-workspace
npx serve -l 8080
```
